# v14 FINAL — Issue Repair Approval + Reviewer Queue + Tina Dictionary

- Fixed Manage Issue modal geometry so it stays inside the usable workspace, to the right of the fixed sidebar and above the fixed footer.
- Every issue receives an automatic repair proposal.
- Superadmin can approve the proposed repair with one button or forward the issue to Reviewer.
- Reviewer gets `Issue Review Queue` and can approve or request changes.
- Tina Dictionary added with catalog management, CRUD, notes, morphology, collocations, examples, pronunciation metadata, tags and learning status.

- Header Dictionary button: click toggles Word Tools; double-click opens Tina Dictionary.
- Cmd/Ctrl+K opens or focuses dictionary search; N creates a new entry; Cmd/Ctrl+Enter saves.
- Repair approval creates a governed remediation decision. It does not silently rewrite source code.
