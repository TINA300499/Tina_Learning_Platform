A public GitHub repository is visible to the public, but that does not by itself grant an open-source license. Choose a license deliberately before inviting reuse or contributions.

Common choices to evaluate:
- MIT — permissive.
- Apache-2.0 — permissive with an explicit patent grant.
- GPL-3.0 — copyleft.
- Keep no license for now — source is publicly viewable but reuse rights remain restricted by default.
